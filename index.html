Positional number system

N = dₙbⁿ + dₙ₋₁bⁿ⁻¹ + … + d₀b⁰

Fraction: d₋₁b⁻¹ + d₋₂b⁻² + …

Decimal → other base

Integer: repeated division

Fraction: repeated multiplication

Why does this work? (কেন কাজ করে?)

প্রতিটি Number System-এর একটি Base থাকে।
Binary → Base 2, Octal → Base 8, Decimal → Base 10, Hexadecimal → Base 16।

একটি সংখ্যার প্রতিটি digit-এর position অনুযায়ী base-এর power ব্যবহার করা হয়। যেমন 101₂ = 1×2² + 0×2¹ + 1×2⁰ = 5।

Binary ↔ Octal/Hex shortcut: 8 = 2³ এবং 16 = 2⁴, তাই 3 bit = 1 octal digit, 4 bit = 1 hex digit।
